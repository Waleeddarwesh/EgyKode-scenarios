# Git Branching & Collaboration

A repository is waiting at `/root/shop`. It has two commits on `main` — the
second one is a colleague's change to the same line you are about to touch.

You will branch, rebase onto their work, resolve the conflict that causes, and
then recover a commit after deliberately destroying it.

Everything here is a real repository. Nothing is simulated.

```
cd /root/shop
git log --oneline
```
